О программе

Платформа анализирует технику выполнения упражнений по видео и по камере, автоматически расставляет ключевые точки тела и помогает отслеживать прогресс пользователя.

  • Раздел Тренировки запускает камеру, отображает скелет и сохраняет ваши видео по упражнениям.
  • Личный кабинет находится во вкладке Профиль — там можно редактировать данные и просматривать историю тренировок.
  • Консоль разработчика доступна только аккаунту admin через кнопку Разработчик в верхнем меню.
Профиль пользователя

Удаление аккаунта необратимо: профиль и все сохранённые видео тренировок будут удалены.
